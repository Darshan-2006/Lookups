# Lookups
# Excel Lookup Functions: VLOOKUP, HLOOKUP, XLOOKUP

Hands-on practice workbooks for Excel's lookup family, built around a small sales-commission dataset and a vegetable price list.

## Repository Contents

| File | Purpose |
|------|---------|
| `README.md` | This guide |
| `Lookups-START_v3.xlsx` | Main workbook: 12 sheets covering VLOOKUP, HLOOKUP, XLOOKUP (basic, multi-column, wildcard), MATCH, and Sum/Filter practice |
| `Vlookup.xlsx` | Beginner VLOOKUP exercise on a vegetable cost/price table |

## Topics Covered

- `VLOOKUP`: exact match, column index, duplicates
- `HLOOKUP`: horizontal lookup, table references
- `XLOOKUP`: default value, multi-column return, wildcards, reverse search
- `MATCH`: finding index positions
- Structured table references (`Table1[[#This Row],[Names ]]`)
- Practice sheets for lookups by year and Sum & Filter

## File 2: `Vlookup.xlsx`

- `Sheet1` (`Table1`): 10 vegetables with ProductID, CostPrice, SellingPrice, Profit (`=D2-C2`)
- `Sheet2` (`Table2`): lookup sheet that pulls SellingPrice, Profit, CostPrice by vegetable name
- Shows that **column order in the result can differ from the source**, because only the column index changes

```excel
=VLOOKUP(A2,Sheet1!$B$1:$E$11,3,0)      ' SellingPrice
=VLOOKUP(A2,Sheet1!$B$1:$E$11,4,FALSE)  ' Profit
=VLOOKUP(A2,Sheet1!$B$1:$E$11,2,0)      ' CostPrice
```

## Formula Cheat Sheet (from the workbooks)

### VLOOKUP
```excel
=VLOOKUP(A2, Vlookup!$A$1:$E$23, 5, 0)
```
- Looks up in the **first column** of the range
- `5` = fifth column (Commission)
- `0` = exact match

### HLOOKUP
```excel
=HLOOKUP(B9, $C$2:$X$6, 5, 0)
```
- Looks up across the **top row**
- `5` = fifth row (Commission)

### XLOOKUP
```excel
=XLOOKUP(A12, Xlookup!$E$2:$E$23, Xlookup!$D$2:$D$23, "Not Available")
```
- Lookup array and return array are separate, so the lookup column can be **anywhere**
- 4th argument = text shown when no match

### XLOOKUP: multiple columns
```excel
=XLOOKUP(G2, A1:A23, D1:E23)
```
- Returns Sale Amount and Commission together (spills into two cells)

### XLOOKUP: wildcards
```excel
=XLOOKUP(G8&"*", A1:A13, D1:D13, , 2)         ' starts with
=XLOOKUP("*"&G12, A2:A13, D2:D13, , 2)        ' ends with
=XLOOKUP("*"&G13&"*", A2:A13, D2:D13, , 2)    ' contains
=XLOOKUP("*"&G14, A2:A13, D2:D13, , 2, -1)    ' last match (search from bottom)
```
- Match mode `2` enables wildcards
- Search mode `-1` searches last to first

### MATCH
```excel
=MATCH(A1, Sheet2!A1:A6, 0)
```
- Returns the position, not the value

## VLOOKUP vs HLOOKUP vs XLOOKUP

| Feature | VLOOKUP | HLOOKUP | XLOOKUP |
|---------|---------|---------|---------|
| Direction | Vertical | Horizontal | Both |
| Lookup column position | Must be first | Must be top row | Anywhere |
| Look left | No | No | Yes |
| Column/row index number | Required | Required | Not needed |
| Built-in "not found" text | No | No | Yes |
| Wildcards | Yes | Yes | Yes (match mode 2) |
| Reverse search | No | No | Yes (search mode -1) |
| Multi-column return | No | No | Yes |
| Availability | All versions | All versions | Excel 2021 / 365 |

## Things to Watch Out For

- **Duplicates:** lookups return the **first** match only (see `Sheet1`: Harley Fritz and Kennedi Singh each appear twice)
- **Typos and spaces:** `Sheet3` returns `#N/A` because `Sheet2` has "Caulifower" while the lookup says "Cauliflower". "Brinjal " also has a trailing space
- **Case:** lookups are case-insensitive, so "kennedi Singh" still matches
- **Trailing space in header:** the table column is named `Names ` (with a space), which appears in the structured reference
- **`Sheet4!C16`:** the XLOOKUP points to `B16` (the previous result) instead of `A16` (the name). It displays "Not Available" either way, but the reference should be `A16`
- **`Xlookup!H9`:** `MATCH` without a match type defaults to approximate match on unsorted data, so it returns `23` for "Nyla Novak". Use `0` for exact match
- **Practice cells:** some answer cells are intentionally blank (`Vlookup`, `Hlookup`, `Xlookup 5`, `SumFilter`) for you to fill in

## How to Use

- Clone or download the repo
- Open `Lookups-START_v3.xlsx` in **Excel 2021 or Microsoft 365** (needed for XLOOKUP)
- Start with `Vlookup`, then follow the sheets left to right
- Fill the blank practice cells, then compare with the examples
- Try `Vlookup.xlsx` first if you are brand new to lookups

### Compatibility
- VLOOKUP / HLOOKUP / MATCH: all Excel versions
- XLOOKUP sheets: Excel 2021+, Microsoft 365, or recent LibreOffice
- Older Excel shows `#NAME?` on XLOOKUP cells
